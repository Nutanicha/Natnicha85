นางสาวณัฐนิชา รัตนศรี จากสาขานวัตกรรมดิจิทัล คณะเทคโนโลยีสารสนเทศค่ะ ดิฉันเป็นคนชอบเรียนรู้สิ่งใหม่และหลงใหลในการตัดต่อวิดีโอ ด้วยประสบการณ์ฝึกงานที่ Lotus's Go Fresh เป็นเวลา 6 เดือน ทำให้ดิฉันเข้าใจกระบวนการทำงานจริง มีความรับผิดชอบ และพร้อมที่จะนำทักษะด้านนวัตกรรมดิจิทัลรวมถึงเทคนิคการตัดต่อมาสร้างสรรค์ผลงานใหม่ๆอยู่เสมอ
